# Pomodoro Study Clock

A custom embedded systems project that automates the Pomodoro study method using an Arduino, multiplexed seven-segment displays, a custom PCB designed in KiCad, and a custom enclosure designed in Onshape.

## Features

- 45-minute study timer and 15-minute break timer
- Multiplexed 4-digit seven-segment countdown display
- Session counter display
- Buzzer notifications and button controls
- Custom PCB and enclosure

## Hardware

- Arduino microcontroller
- 4-digit seven-segment display
- Additional display for session tracking
- SN74HC595 shift register
- Push buttons
- Piezo buzzer

## Engineering Concepts

- Embedded systems programming
- Seven-segment display multiplexing
- Shift register integration (SN74HC595)
- Timer and state-machine logic
- Digital electronics and circuit design
- PCB design and routing in KiCad
- CAD and enclosure design in Onshape

## Development Process

1. Learned seven-segment display control and multiplexing.
2. Developed timing, display, and user-input logic on Arduino.
3. Integrated a shift register to expand available I/O.
4. Prototyped and tested the circuit on a breadboard.
5. Designed a custom enclosure in Onshape.
6. Created a custom PCB in KiCad and prepared it for manufacturing.
